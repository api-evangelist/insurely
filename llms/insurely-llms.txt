# Insurely

> Insurely provides real-time access to consented, structured financial data across investments, pensions, insurance, savings, and credit for European financial institutions, fintechs, and AI companies. Its Open Finance API lets you create end users, capture consent, run data collections (including PSD2 banking data), and retrieve structured wealth data via a signal-and-fetch webhook model.

Base URL: https://api.insurely.com
API version header: `Insurely-Version: 2026-04-01`
Authentication: static API key in the `authorization-token` header (backend) plus a per-user JWT bearer token (consumer-scoped operations).

## Operations
- POST /users — create user
- POST /users/{userUuid}/sessions — mint per-user JWT session
- POST /consents — create data-access consent
- GET /consents/{consentId}/status — poll consent status
- POST /collections — initiate a data collection
- GET /wealth/collection/{collectionId}/status — poll collection status
- GET /collections/{collectionId}/wealth/data — retrieve collected data
- GET /companies/availability — check institution PSD2 support
